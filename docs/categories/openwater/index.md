# Water purifiers

Working name: **OpenWater**. This reference covers manufacturer-identified filter cartridges and their stated host units.

## Find a replacement

- [Units](units/index.md)
- [Composite cartridges](prefilters/index.md)
- [RO cartridges](ro-cartridges/index.md)
- [Faucet cartridges](faucet-cartridges/index.md)

Match the full unit name, cartridge code and stage. A name such as PPC1 or RO1 can appear in different product families; it does not by itself establish a common mounting interface. Composite cartridges and RO cartridges occupy separate positions and are recorded separately. PPC and PCB assemblies can combine several treatment functions; their position and role follow the named host system.

Compatibility entries describe manufacturer claims about a cartridge fitting a named unit. They do not establish treatment performance for a water supply, certification, or equivalence between filter media.

## Status

**Reference layer only.** No cartridge interface in this category has a project measured baseline. The initial coverage follows exact manufacturer replacement listings. Other brands and regional variants remain absent where an exact match has not been verified.
