# Humidifiers

Working name: **OpenMist**. This reference distinguishes replaceable evaporative wicks from other humidifier architectures.

## Find a replacement

- [Units](units/index.md)
- [Replacement wicks](wicks/index.md)

A washable disc stack, a replaceable fabric wick and an ultrasonic water tank are different systems. A humidifier page without a replacement link means that this archive has no sourced fit claim for that unit. It does not establish that a replacement is unavailable.

Use the exact host model named on a wick listing. Similar dimensions or the same advertised output do not establish cross-fit.

## Status

**Reference layer only.** The entries record manufacturer claims, with no project measurements or measured compatibility baseline. A source review date does not certify local stock or a replacement interval.
